# Project 1: Projectile Motion Simulator (প্রক্ষেপণ গতি সিমুলেটর)

**বিষয়:** Physics + Math | **লেভেল:** Basic Python (variables, loops, functions)

## ১. ধারণা (Concept)

যখন কোনো বস্তুকে (যেমন একটা বল) মাটি থেকে একটা কোণে (angle) ছোঁড়া হয়, তখন সেটি একটা বাঁকানো পথ (curved path) ধরে চলে এবং শেষে মাটিতে পড়ে। এই গতিকে বলে **Projectile Motion**।

দৈনন্দিন জীবনে এর উদাহরণ:
- ক্রিকেটে বল ছোঁড়া বা শট মারা
- বাস্কেটবলে শুট করা
- কামানের গোলা বা রকেটের প্রাথমিক গতিপথ
- ফোয়ারার পানির ধারা

এই Project-এ আমরা Python দিয়ে হিসাব করব — কোন কোণ ও গতিবেগে ছোঁড়লে বস্তুটি কতদূর যাবে, কতক্ষণ বাতাসে থাকবে, এবং সর্বোচ্চ কত উঁচুতে উঠবে। তারপর সেটিকে গ্রাফ ও একটা Interactive Web App দিয়ে visualize করব।

## ২. তত্ত্ব (Theory)

Projectile motion-কে দুইটা স্বাধীন (independent) অংশে ভাগ করা যায়:

- **Horizontal (x-axis):** কোনো ত্বরণ (acceleration) নেই, বেগ ধ্রুব (constant)
- **Vertical (y-axis):** শুধু মাধ্যাকর্ষণ (gravity, g ≈ 9.8 m/s²) কাজ করে, তাই বেগ ক্রমাগত কমে-বাড়ে

শুরুর বেগ `v`, কোণ `θ` হলে:

```
vx = v * cos(θ)      # অনুভূমিক বেগ (সময়ের সাথে অপরিবর্তিত)
vy = v * sin(θ)      # উলম্ব বেগের প্রাথমিক মান

x(t) = vx * t
y(t) = vy * t - 0.5 * g * t²
```

এখান থেকে তিনটা গুরুত্বপূর্ণ রাশি বের করা যায়:

```
সময়কাল (Time of Flight):   T = 2 * vy / g
সর্বোচ্চ উচ্চতা (Max Height): H = vy² / (2 * g)
পাল্লা (Range):              R = vx * T
```

## ৩. কীভাবে কাজ করে (Algorithm)

1. ব্যবহারকারীর কাছ থেকে শুরুর বেগ (v) ও কোণ (θ) নেওয়া
2. কোণকে radian-এ রূপান্তর করা (Python-এর `math` module ডিগ্রিতে কাজ করে না)
3. vx ও vy বের করা
4. t = 0 থেকে শুরু করে ছোট ছোট সময়ের ধাপে (time step) x(t), y(t) হিসাব করে একটা list-এ জমা রাখা
5. যখন y(t) আবার ০-তে (বা তার নিচে) নেমে আসবে, লুপ থামানো
6. পুরো path-টা matplotlib দিয়ে প্লট করা, এবং T, H, R প্রিন্ট করা

## ৪. ধাপে ধাপে তৈরি (Build it)

`projectile_motion.py` ফাইলটা ৫টা ধাপে ভাগ করা আছে — প্রতিটা ধাপ একটা function হিসেবে লেখা, যাতে বোঝা সহজ হয়:

| ধাপ | Function | কাজ |
|---|---|---|
| ১ | `get_components(v, angle_deg)` | v ও θ থেকে vx, vy বের করা |
| ২ | `time_of_flight(vy, g)` | বাতাসে থাকার মোট সময় |
| ৩ | `max_height(vy, g)` | সর্বোচ্চ উচ্চতা |
| ৪ | `trajectory(vx, vy, g, dt)` | পুরো পথের (x, y) বিন্দুগুলোর list |
| ৫ | `plot_trajectory(points)` | গ্রাফ আঁকা |

ফাইলটা নিজে খুলে পড়ুন এবং `python projectile_motion.py` চালিয়ে দেখুন। প্রতিটা function-এর উপরে কমেন্টে বোঝানো আছে ভিতরে কী হচ্ছে।
